# Security policy — Plancia

Plancia è una UI web owner servita tramite API e sessioni same-origin. Segnalare vulnerabilità attraverso il canale privato **Security → Report a vulnerability** del repository GitHub quando disponibile. Non inserire token, cookie, indirizzi privati, profili personali o dettagli sfruttabili in issue pubbliche.

I problemi del client React/Vite e della verifica degli artefatti sono di competenza di questo repository. I bug del donor Muxin ritirato vanno segnalati all'[upstream](https://github.com/LumaryLabsLLC/muxin/security/policy). La documentazione di sicurezza del backend operativo resta nella relativa sorgente privata.
